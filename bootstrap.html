Introduction to Bootstrap

Bootstrap is a popular frontend framework used to build responsive and mobile-friendly websites quickly. It comes with built-in CSS, layout utilities, and components.

Responsive Web Design

RWD ensures websites work on all screen sizes—mobiles, tablets, and desktops.

Viewport Meta Tag

/*meta name="viewport" content="width=device-width, initial-scale=1"*/

Media Query Example

@media (max-width: 600px) {
  body {
    background-color: lightblue;
  }
}

Bootstrap Containers

Containers provide padding and center content.

Types of Containers:

  • container
  • container-fluid
  • container-sm / container-md / container-lg

    .container

  • It is a fixed-width container.
  • The width changes depending on screen size.
  • On small screens it becomes almost full width.
  • On larger screens it stays centered and does not stretch fully.
    • Good for simple centered layouts.

    .container-fluid

  • It is always 100% width.
  • It stretches from the left edge to the right edge of the screen.
  • Works the same on mobile, tablet, and desktop.
  • Best for full-width sections like banners, headers, footers, background sections.

    .container-sm, .container-md, .container-lg, .container-xl, .container-xxl

  • These are responsive containers.
  • They stay full width until a certain screen size.
  • After that screen size, they behave like a normal .container (fixed width).
  • .container-sm
    • → Full width on extra small screens, fixed width on small and above.
  • .container-md
    • → Full width on small screens, fixed width on medium and above.
  • .container-lg
    • → Full width on medium screens, fixed width on large and above.
  • .container-xl
    • → Full width on large screens, fixed width on extra large and above.
  • .container-xxl
    • → Full width on extra large screens, fixed width on extra extra large and above.

Spacing Utilities

Used to apply margin (m) and padding (p). Margin and padding can be combined to control both the space outside and inside an element. Margin creates distance between elements, while padding adds space inside the element around its content. Using both together helps achieve clean spacing, better readability, and a well-structured layout.

  • m-1 to m-5 → margin
  • p-1 to p-5 → padding
  • mt-3 → margin-top
  • px-4 → padding left and right

Bootstrap Buttons

* Bootstrap buttons use the "btn" class along with color classes like `btn-primary`, `btn-success`, or `btn-danger` to create stylish buttons easily. * You can change the *size* of buttons using classes like `btn-lg` (large) and `btn-sm` (small). * Buttons can also be made *outlined*, *full-width*, or *disabled* using extra utility classes.

Bootstrap Cards

  • Cards are flexible content containers used to display text, images, buttons, and lists in a clean, boxed layout.
  • They use the class card and can include parts like card-header, card-body, and card-footer.
  • Cards are fully responsive and easy to style with borders, shadows, images, and background colors.

Bootstrap Navbar

  • A navbar is a responsive navigation bar created using the navbar class for menus, links, and branding.
  • It automatically collapses into a toggle (bread crumbs) menu on small screens using navbar-expand-*.
  • Navbars support brand logos, dropdowns, search bars, and can be styled with light/dark themes like navbar-light and navbar-dark.

Position Utilities

Bootstrap position utilities help you easily control how elements are placed on a page using simple classes like position-static, position-relative, position-absolute, position-fixed, and position-sticky. These classes allow you to move elements using top, bottom, start, and end values without writing custom CSS. They are commonly used for sticky headers, fixed buttons, overlays, and precise element placement.

Shadow Utilities

Bootstrap shadow classes are used to quickly add drop shadows to elements without writing custom CSS. They provide different levels like shadow-sm (small), shadow (regular), and shadow-lg (large) to give depth and make components stand out. Shadows help improve visual hierarchy and make cards, buttons, or boxes look more modern and elevated.

Bootstrap Icons

Bootstrap Icons are a free collection of customizable SVG icons that you can easily use in any webpage. They work with simple classes like bi bi-heart and can be resized or colored using CSS. They are lightweight, scalable, and perfect for adding clean visual symbols to your UI.
